## 一、为什么要单独存一份

同一部古籍在不同版本、不同电子文本中会有差异。这份"维基文库对照本"的作用：

1. **繁简对照**：维基文库为繁体文本，殆知阁本为简体，可对照字形与异体字。
2. **版本对照**：维基文库收录了多种版本（四庫全書本、四部叢刊本），可与通行本对校。
3. **校勘线索**：两本不一致处，正是需要查证的地方——直接影响游戏中人物名、地名、官职名的准确性。
4. **文本互证**：某一本缺字、错字时，另一本可补。

## 二、文件结构

```
11_维基文库对照本/
├── 宋書/
│   ├── 卷1.txt          ← 清理后的纯正文（可读）
│   ├── 卷1.raw.wiki     ← 原始 wikitext（保真，含模板标记）
│   └── ...
├── 魏書 (四庫全書本)/   ← 另一版本，独立目录
├── 資治通鑑/
└── README_对照本说明.md
```

- `.txt`：已清理模板、链接、注释的纯正文，直接可读、可检索。
- `.raw.wiki`：原始未处理文本，保留完整 wiki 标记与元数据（发现 .txt 清理有误时可回溯）。

## 五、与殆知阁本的差异

1. **用字**：维基文库保留繁体与异体字（如「强/強」「里/裏」「后/後」），殆知阁本多用简化通行字。
2. **标点**：两者都有现代标点，但断句可能不同。
3. **卷次编排**：个别书的卷次分合不同。
4. **缺字**：一方缺字（□）处，另一方可能有完整文字。

**使用建议**：游戏中的关键专名（人名、地名、官名、年号），以两本互校；若仍不一致，查中华书局点校本。

## 六、授权说明

- 古籍原文属于**公有领域**，可自由使用。
- 维基文库的页面按 **CC BY-SA** 发布；"原始古籍内容"属公版，"校勘/编排成果"受 CC BY-SA 约束。
- **给游戏的建议**：使用古籍原文内容没有问题；**不要把维基文库的整理文本直接当作自己的整理成果发布**。游戏内文本建议自行标点、改写，并注明史料出处（如「据《魏书》卷九十九」）。
- 引用出处写古籍本身（如《魏书》卷九十九），而非"维基文库"。
