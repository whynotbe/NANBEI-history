# 南北朝历史游戏：史料条件评估报告

> 评估目标：能否做出《太阁立志传》级别的南北朝历史游戏？
> 结论日期：2026-10-03

---

## 一、结论速览

| 目标 | 可行性 | 说明 |
|---|---|---|
| 800～1000 名可扮演武将，每人有姓名、生卒、籍贯、官职、势力归属 | **可行**（以北朝为核心，约 2 人年工作量） | 正史列传 + 墓志 + 造像记 + 僧传 + CBDB，可拼出 3000～8000 人档案 |
| 每人一段"列传"文字 | **部分可行** | 约 200～400 人有足够史料写可靠列传；其余只能写"一句话小传"或标注推测 |
| 数值系统（统率/武力/智谋/魅力） | **完全可行** | 注意：这些数值在《太阁立志传》里也是现代设计，不是史料原物 |
| 地图 + 城郭 + 地名 | **可行** | 水经注、洛阳伽蓝记、元和郡县图志、CBDB 坐标、CHGIS |
| 事件系统（历史事件链） | **远超太阁的素材量** | 资治通鉴 + 正史 + 墓志 + 志怪，事件素材极丰富 |
| 生活/职业系统（士农工商僧道） | **可行且有独到优势** | 吐鲁番户籍文书提供家户级细节；北朝造像记提供工匠、平民姓名 |
| 南朝做到同等人物密度 | **不可行** | 南朝缺档案级材料，只能做"精英层" |
| 逐日/逐月行为复原（像战国日记那样） | **不可行** | 南北朝几乎没有当事人日记/书信集 |

**一句话结论**：以 **500～580 年的北中国（北魏末—东魏西魏—北齐北周）** 为舞台，可以做到"体感接近太阁"，甚至在**事件丰富度、社会层次、宗教神话**上超过太阁；但必须放弃"每个小人物都有可靠档案"的幻想，改用**可信度分级**的设计来吸收史料缺口。

## 二、先搞清楚：《太阁立志传》的数据基础到底是什么

要判断"能不能做到太阁程度"，先得知道太阁的数据从哪来。

### 2.1 日本战国的史料家底

1. **当事人一手文书（这是核心优势）**
   - 战国大名、家臣、寺社、商人留下的书信、判物、朱印状、起请文，现存原件数量以十万件计。
   - 东京大学史料编纂所《大日本古文書》《大日本史料》等已系统编纂数万件。
   - 意义：可以直接看到某人在某年某月做了什么、写给谁、什么语气。

2. **同时代日记与记录**
   - 公家日记：《言継卿記》《晴右記》《兼見卿記》等，记录朝廷与武家动态。
   - 武家记录：《信長公記》《三河物語》《井伊家伝記》等。
   - 耶稣会年报、朝鲜使节记录：外部视角。

3. **江户时代的家谱与地志（这是"小人物"的来源）**
   - 《寛政重修諸家譜》收录 1500 余家旗本/大名系谱。
   - 各藩藩史、藩翰譜、地志、寺社缘起。
   - 意义：一个中下级武士，可能正史无名，但家谱和地志里留下了名字、俸禄、居所。

4. **近代以来的整理**
   - 明治以来 150 年的实证史学研究。
   - 县史、市町村史（战后出版数千册），把村落级信息全部翻检过一遍。

5. **现代数字化**
   - 「日本歴史地名大系」「国史大辞典」、各大学史料数据库、JACAR，全部可检索。

### 2.2 关键认知

> **《太阁立志传》中的数值（统率、武力、智谋、魅力）不是史料，是现代游戏设计。**
> 史料能提供的是：这个人做过什么、和谁有关系、在哪个位置、什么性格（评价）。
> 所以"史料不足"的焦虑，有一部分是把"游戏数值"误当成了"史料数据"。

太阁真正依赖史料的是：
- **名录**（有多少人名可考）→ 决定了武将池大小
- **关系网**（谁是谁的家臣、亲戚、仇敌）→ 决定了势力与事件
- **事件**（某年某事）→ 决定了剧情
- **地点**（城、村、寺）→ 决定了地图

## 三、南北朝的史料家底（分层清点）

时间范围：**420（刘宋代晋）～589（隋灭陈）**，若含十六国与北魏前期则 386 起。

### 3.1 第一层：正史（骨架）

| 史书 | 成书 | 作者 | 性质 |
|---|---|---|---|
| 《宋书》100卷 | 488 | 沈约（南朝梁） | 当代人修当代史，含八志（州郡、百官、符瑞、五行） |
| 《南齐书》59卷 | 6世纪初 | 萧子显（梁） | 当代人修当代史 |
| 《梁书》56卷 | 636 | 姚思廉（唐） | 唐修，但姚氏父子有家学 |
| 《陈书》36卷 | 636 | 姚思廉（唐） | 唐修 |
| 《魏书》114卷 | 554 | 魏收（北齐） | 当代人修当代史，含《释老志》《官氏志》《地形志》 |
| 《北齐书》50卷 | 636 | 李百药（唐） | 唐修，大量残缺 |
| 《周书》50卷 | 636 | 令狐德棻（唐） | 唐修 |
| 《南史》80卷 | 659 | 李延寿（唐） | 删并南朝四史 |
| 《北史》100卷 | 659 | 李延寿（唐） | 删并北朝四史 + 隋 |
| 《晋书》130卷 | 648 | 房玄龄等（唐） | 含十六国载记 |
| 《隋书》85卷 | 656 | 魏征等（唐） | 含《经籍志》（目录学基石）、《地理志》 |

- 合计约 **500 万字**，其中南北朝部分约 350～400 万字。
- 有独立列传的人物：约 **2000～3000 人**（含大量附传）。
- 局限：唐初编纂的史书带有政治取舍；北齐、北周史书残缺严重（《北齐书》仅存约 1/3 原文）。

### 3.2 第二层：墓志铭（这是南北朝独有的富矿）

- 现存南北朝墓志（含砖志、塔铭）**数千方**，其中北魏洛阳地区出土最密集。
- 代表作：《汉魏南北朝墓志汇编》（赵超）收录约 3000 方；《新出魏晋南北朝墓志疏证》（罗新、叶炜）补录新出；《汉魏南北朝墓志集释》（赵万里）。
- 一方墓志通常提供：**姓名、字号、籍贯、曾祖/祖/父三代名讳与官职、本人历官、卒年卒月、葬地、妻子的家世、子女**。
- 意义：**这就是南北朝的"家谱 + 履历书"**。正史无传的中层官僚、女性、胡族贵族、地方豪强，靠墓志留下完整档案。
- 局限：北朝远多于南朝（南朝墓志出土少，且南方酸性土壤不利于石刻保存）；墓志有溢美倾向。

### 3.3 第三层：造像记与石刻（平民层）

- 龙门石窟现存碑刻题记约 **2800 品**；云冈、巩县、响堂山、麦积山、莫高窟等合计数千品。
- 造像记常记录：**发愿人姓名、籍贯、官职或身份（邑子/邑主/像主）、家庭成员、祈愿内容**。
- 意义：这是南北朝少有的**平民与基层社会**的姓名来源，包含大量女性、工匠、村落组织（邑义）。
- 另有碑刻、摩崖、买地券、镇墓文。

### 3.4 第四层：出土文书（家户级细节，北朝独有）

- **吐鲁番阿斯塔那古墓群**出土北朝至唐代文书数千件（《吐鲁番出土文书》10 册）。
  - 类型：户籍、田亩帐、差科帐、契约（租佃、借贷、买卖）、随葬衣物疏、书信、佛经题记。
  - 意义：能看到**具体某村某户、几口人、多少地、欠多少税**——这是比日本战国"检地帐"更早、更系统的人口经济数据。
- 敦煌文书中的北朝写卷（部分）、楼兰/尼雅简牍（更早）。
- 局限：地理上限于吐鲁番—河西走廊，不能覆盖中原。

### 3.5 第五层：宗教文献（南北朝人物密度最高的来源之一）

**佛教**：
- 《高僧传》14卷（慧皎，519）：**正传 257 人，附见 200 余人**。
- 《续高僧传》30卷（道宣，645）：**正传 340 人，附见 160 余人**（含北朝—隋）。
- 《比丘尼传》（宝唱）：记载南朝尼僧 65 人。
- 《出三藏记集》（僧祐）：译经目录与译者传记。
- 《弘明集》《广弘明集》：佛道论争、护法文献，涉及大量士人。
- 《法苑珠林》100卷（道世，668）：佛教百科全书 + 感应故事集，保存大量佚书。
- 《经律异相》《诸经要集》：分类佛典故事集。
- 《辨正论》《破邪论》《集古今佛道论衡》：佛道论争，牵涉皇帝、道士、僧人的具体活动。
- 意义：**僧传提供了数以千计的人物**，且这批人在正史里往往没有位置。

**道教**：
- 《真诰》（陶弘景）：上清派神谱、修真记录，包含人物与神话体系。
- 《抱朴子》（葛洪，东晋）：道教理论。
- 《神仙传》《汉武帝内传》《海内十洲记》《洞冥记》：神仙叙事。
- 道藏中另有《无上秘要》《太上洞玄灵宝》等六朝道经。

### 3.6 第六层：地理与城市（地图来源）

- 《洛阳伽蓝记》（杨衒之，547）：**北魏洛阳城内城外 1000+ 座佛寺、里坊、宅邸、园林**，是目前唯一能精细复原一座南北朝都城的文献。
- 《水经注》（郦道元，6世纪初）：1252 条河流沿岸的城邑、关隘、名胜、古迹。
- 《建康实录》（许嵩，唐）：六朝建康编年 + 地理。
- 《六朝事迹编类》（张敦颐，南宋）：建康遗迹考。
- 《元和郡县图志》（李吉甫，唐）：州县沿革、山川、户口。
- 《太平寰宇记》（乐史，北宋）：州县级地理总志。
- 《魏书·地形志》《宋书·州郡志》《隋书·地理志》：政区数据。
- 配套：CBDB 的 ADDR_CODES 表已含 3 万条地名的**经纬度坐标**（古代地名 ↔ CHGIS 点）。

### 3.7 第七层：文集、总集、类书（人物与事件的海洋）

- 《全上古三代秦汉三国六朝文》（严可均，清）：收录至隋的全部存世散文，**作者三千余家**，包含诏令、表疏、碑铭、书信、佛道论难。
- 《先秦汉魏晋南北朝诗》（逯钦立）：诗歌总集。
- 《文苑英华》《文选》《玉台新咏》《乐府诗集》《古诗纪》：文学总集。
- 《艺文类聚》（624）、《初学记》（728）、《太平御览》（983）、《册府元龟》（1013）、《北堂书钞》：类书，**保存了大量已佚史料的片段**。例如《太平御览》引书 1690 种，绝大多数已亡佚。
- 《世说新语》及刘孝标注：注中引用了 400 余种已佚的魏晋史料，是人物言行的重要来源。

### 3.8 第八层：志怪小说（神话与民间信仰）

- 六朝志怪：《搜神记》《搜神后记》《拾遗记》《异苑》《述异记》《幽明录》《宣验记》《冥祥记》《还冤志》《列异传》《志怪》《齐谐记》《续齐谐记》《录异传》《灵鬼志》《玄中记》《冥通记》等。
- 意义：既是**神话素材库**，也是**民间社会与信仰的侧面记录**（这些故事往往有具体人名、地名、年代）。

## 四、逐项对比：太阁 vs 南北朝

| 维度 | 日本战国（1560-1600） | 南北朝（386-589） | 差距 |
|---|---|---|---|
| 当事人一手文书 | 数十万件 | 极少（尺牍、造像记、文书残卷） | **大** |
| 同时代日记 | 丰富（公家/武家日记） | 无（只有《洛阳伽蓝记》这类回忆性著作） | **极大** |
| 编年史 | 军记物语 + 日记 + 文书 | 正史 + 资治通鉴（均为后修） | 中 |
| 人名可考总量 | 上万 | 1～2 万（正史 3000 + 墓志 5000 + 造像 + 僧传 2000 + 文书） | 中 |
| 小人物档案 | 家谱 + 地志，覆盖到村 | 墓志 + 造像记，覆盖到县城与村落组织 | **中（北朝）/ 极大（南朝）** |
| 家户经济数据 | 检地帐、人别帐、村方文书 | 吐鲁番户籍/田亩帐（仅限吐鲁番） | 中 |
| 城市复原 | 城下町图、绘图 | 洛阳（洛阳伽蓝记）可精细复原；建康、邺城、平城次之 | 中 |
| 家族/婚姻网络 | 家谱 + 系图 | 墓志世系 + 正史 + 士族谱（多佚） | 中 |
| 现代数字化 | 极完善、可全文检索 | 正史可检索；墓志部分数字化；造像记分散 | **大** |
| 现代研究积累 | 300 年考据 + 150 年实证 | 约 100 年（20 世纪以来） | 中 |
| 总评 | 基准 | **北朝约 50～70% 可及，南朝约 20～30%** | — |

## 五、南北朝的"富矿"：能超过太阁的地方

1. **事件素材密度极高**：仅《资治通鉴》南北朝部分就有上千个可 dramatize 的事件（河阴之变、侯景之乱、玉璧之战、沙苑之战、邙山之战、江陵焚书……）。
2. **社会层次更丰富**：士族、寒人、胡族酋豪、僧尼、道士、工匠、商人、女官、乐户——每一类都有史料支撑。
3. **宗教神话系统完整且独特**：佛教地狱/净土/观音信仰 + 道教上清神谱 + 民间志怪 + 北族起源神话（拓跋鲜卑、柔然、突厥的狼生传说），可以做成《太阁》没有的"信仰层"。
4. **女性角色可挖掘**：北朝女性（冯太后、娄昭君、胡太后、独孤氏姐妹）在正史与墓志中形象鲜明；南朝有《世说新语》中的女性群像。
5. **都市生活细节**：《洛阳伽蓝记》里有酒楼、胡商、杂技、佛诞游行、市井斗殴——可直接转化为游戏场景。
6. **制度玩法**：九品中正、清议、府兵、均田、三长制、六官制——可以设计成《太阁》没有的"制度改革"系统。
7. **多语言/多族群**：鲜卑语、汉语、敕勒语、粟特语——河西与洛阳出土的粟特人墓志（如安伽、史君）提供了胡商社群素材。

## 六、南北朝的"死角"：做不到的地方

1. **没有逐日行为记录**：无法像战国研究那样复原"某人某月某日在哪里做了什么"。南朝尤其。
2. **南朝基层空白**：除建康附近与少数大族，南朝乡村几乎无资料。做南朝游戏只能围绕都城与士族。
3. **北朝档案也限于点状**：墓志给的是"某人一生"的快照，而不是连续的家族档案（缺乏连续的家谱链）。
4. **人名同名、异名问题严重**：南北朝人物常用字、小字、胡名汉名并用（如拓跋焘/佛狸伐、萧衍/萧叔达/梁武帝），需要做名字消歧。
5. **年份/月日的精度有限**：多数事件只能定位到年、月，无法到日。部分人物生卒年只能靠推测（CBDB 中 2505 人有生卒年数据，剩下多数没有）。
6. **没有商业化授权的一站式数据库**：不像日本有"日本历史地名大系"可直接授权。需要自己从多个来源拼装并处理授权。

## 七、可行性分级结论

### ✅ 完全可以做到（可直接对标太阁）
- 1000+ 人物名录（北朝为主，含姓名、官职、年代、关系）
- 势力与势力消长（北魏→东西魏→北齐北周→隋）
- 地图与城池（洛阳、邺、晋阳、长安、平城、建康……）
- 历史事件链（500-580 年几乎每年都有大事件）
- 官职/制度系统（真正有史料支撑，比太阁的"功勋/知行"更复杂）
- 宗教与神话系统（佛教 + 道教 + 志怪 + 北族神话）

### ⚠️ 只能做到"半专业化"（需明确标注推测）
- 小人物的详细数值与列传
- 民间生活细节（除吐鲁番外）
- 女性与平民的完整人生轨迹
- 精确的地理距离与行军路线（天气/道路状况）

### ❌ 做不到（不要浪费预算）
- 南朝同等密度的基层人物
- 逐月/逐日的时间线复原
- 1000 人的完全可靠生卒年
- 客观无争议的"历史真相"（凡史料有分歧，游戏中必须做选择）

## 八、推荐落地方案

### 8.1 时代选择（重要）
| 方案 | 时段 | 优势 | 风险 |
|---|---|---|---|
| **A（推荐）** | 500-580：北魏末 → 河阴之变 → 东西魏 → 北齐北周 | 墓志最密集、正史最详细、事件最密集、佛教素材最多 | 政治线复杂，需做好势力系统 |
| B | 383-450：淝水 → 北魏崛起 → 元嘉北伐 | 故事线清晰，正史充足 | 墓志素材少 |
| C | 547-589：侯景之乱 → 南朝衰亡 → 隋统一 | 戏剧性最强 | 南朝史料薄；收尾线索单一 |

### 8.2 数据分层设计（核心建议）
给每个数据项标注可信度：
- **A 级（史料直证）**：正史/墓志/造像记/文书原文明确记载。
- **B 级（合理推测）**：有间接证据或多方互证。
- **C 级（设计虚构）**：为游戏性补全，但符合时代逻辑。
玩家界面可选择性显示"史实/推测"标记——这本身可以成为游戏的特色卖点（像《刺客信条》的 Discovery Tour）。

### 8.3 数据库设计（建议）
- `persons`（人物）：ID、正史名、别名字号、胡名、性别、生卒、籍贯、族属、门第
- `offices`（官职任命）：人物、官职、起讫年、机构、来源
- `relations`（关系）：血缘、婚姻、师生、僚属、仇敌
- `places`（地点）：古名、今地、经纬度、类型（州/郡/县/城/寺/关）
- `events`（事件）：年份、地点、参与人、来源、可信度
- `sources`（史料出处）：每条数据的出处（书名 + 卷数 + 页码），便于考据与展示

## 九、工作量估算（1 名熟悉史料的策划 + 1 名程序/美术）

| 模块 | 工作量 |
|---|---|
| 人物数据库（1000 人可玩 + 3000 人 NPC） | 3～6 个月 |
| 地点与地图数据 | 1～3 个月 |
| 事件数据库（300～500 个事件） | 3～6 个月 |
| 官职/制度系统 | 3～6 个月 |
| 宗教神话系统 | 2～4 个月 |
| 史料校核（可信度标注） | 持续进行 |

**结论：可行，但这是一款"重数据"的游戏。核心成本不在美术，而在史料的整理、分级与验证。**

## 十、给你的最终建议

1. **不要试图"全史还原"**。选 500-580 年的北中国，把这一段时间做深，胜过整个南北朝做浅。
2. **把"史料不足"变成玩法**：可信度分级、史料来源展示、多版本事件对照——这是南北朝题材独有的魅力。
3. **优先做人物库**：它是所有系统的地基。CBDB 已给你 4951 人的骨架，墓志、造像记可以再加 2000～3000 人。
4. **神话不要当附庸**：佛教地狱/净土、道教洞天、志怪鬼话可以直接做成事件系统与地图副本，这是太阁完全没有的层次。
5. **南朝做"精品线"，不做"大地图"**：以建康为中心，围绕士族、皇族、僧尼设计 100～200 人的剧情线即可。
