# 从史料到游戏：落地指南

> 目标：把"史料"变成"可直接编程的数据"。本文件给出数据结构、样例与设计方法。

---

## 一、总体架构建议

```
史料层（古籍文本 + 墓志 + 造像 + CBDB）
        ↓  人工/脚本提取
数据层（persons / offices / relations / places / events / sources）
        ↓  策划加工
游戏层（人物卡 / 事件卡 / 地图 / 系统）
        ↓
表现层（立绘 / UI / 文本）
```

**关键原则**：数据层必须保留 `source`（出处）与 `confidence`（可信度）字段。这两个字段是南北朝题材最大的护城河。

---

## 二、人物卡数据结构

### 2.1 字段设计

| 字段 | 说明 | 示例 |
|---|---|---|
| id | 唯一 ID | P0001 |
| name | 正史名 | 高欢 |
| alt_names | 别名/字/小字/胡名 | 贺六浑（小字）、齐神武（谥） |
| birth / death | 生卒（可空/可模糊） | 496 / 547 |
| birth_note | 生卒考证备注 | "生年据《北齐书》推" |
| origin | 籍贯 | 渤海蓨（今河北景县） |
| origin_id | 地点 ID | L00123 |
| ethnicity | 族属 | 汉（鲜卑化） |
| clan | 门第/郡望 | 渤海高氏（伪托） |
| faction | 势力 | 东魏/北齐 |
| status | 身份 | 权臣、六镇军官 |
| offices | 历任官职 | 见 offices 表 |
| relations | 关系 | 见 relations 表 |
| events | 参与事件 | 见 events 表 |
| traits | 性格/能力描述（史料原文） | "少有大度""轻财好士" |
| biography | 列传（可长可短） | … |
| playable | 是否适合做主角 | 是/否 + 理由 |
| source | 出处 | 《北齐书》卷一至卷二《神武纪》 |
| confidence | 可信度 | A |

### 2.3 数值（统率/武力/智谋…）怎么定

**方法：史料 → 证据项 → 数值**，避免凭感觉拍脑袋。

| 数值 | 证据来源举例 |
|---|---|
| 统率 | 大规模战役胜负、部下规模、是否被推为盟主 |
| 武力 | 个人武勇记载（"力能扛鼎""单骑陷阵"）、是否亲临前线 |
| 智谋 | 计谋记载、政治操作、是否善终 |
| 内政 | 治理记载（劝农、兴学、修渠）、户口增长 |
| 魅力 | 投奔者数量、士人评价、是否被追念 |
| 宗教 | 造像、写经、护法记录、与僧道交往 |
| 门第 | 郡望、婚姻圈、仕宦起点（可作为"初始资源"而非能力值） |

> 建议：把"门第"做成**初始资源/出身**，而不是能力值——这才能体现南北朝的阶层逻辑。

## 三、事件卡数据结构

### 3.1 字段

| 字段 | 说明 |
|---|---|
| id / name | 事件 ID / 名称 |
| year / month | 时间（可模糊） |
| place_id | 地点 |
| participants | 参与人 |
| type | 政治/军事/宗教/灾异/私人 |
| trigger | 触发条件（年份、势力、人物状态） |
| choices | 玩家选项（若有） |
| outcomes | 分支结果 |
| history | 史实结果（供玩家对照） |
| drama | 戏剧性评级 1-5 |
| confidence | A/B/C |
| source | 出处 |

### 3.2 样例

```
事件：河阴之变
时间：528 年（武泰元年）四月
地点：河阴（今河南孟津）
参与：尔朱荣、胡太后、幼帝元钊、王公百官两千余人
类型：政治屠杀
经过：尔朱荣以"清君侧"为名入洛，将胡太后与幼帝沉河，随后在河阴屠杀朝臣两千余人，
      另立元子攸为帝（孝庄帝）。
影响：北魏中央士族集团被摧毁 → 尔朱氏专政 → 高欢、宇文泰崛起 → 北魏分裂
戏剧性：5
可信度：A
出处：《魏书》卷七四《尔朱荣传》、《洛阳伽蓝记》卷一、《资治通鉴》卷一五二
游戏化：可由玩家选择"是否参与屠杀"或"是否劝谏"，导致声望/势力关系剧变
```

## 四、地图数据

### 4.1 需要的图层

| 图层 | 数据来源 |
|---|---|
| 政区（州/郡/县） | 《魏书·地形志》《宋书·州郡志》《隋书·地理志》，CBDB ADDR_CODES |
| 自然地理（河流、山脉） | 《水经注》，现代 GIS 底图 |
| 城市（城、郭、里坊） | 《洛阳伽蓝记》（洛阳 1000+ 寺院与里坊）、《建康实录》 |
| 关隘与道路 | 《水经注》《读史方舆纪要》 |
| 佛寺与石窟 | 《洛阳伽蓝记》、造像记、宿白《中国石窟寺研究》 |
| 坐标 | CBDB `x_coord` / `y_coord`（3 万条）+ CHGIS |

### 4.2 洛阳城（唯一可精细复原的都城）

《洛阳伽蓝记》提供了：
- 城内：宫城、太极殿、永宁寺、铜驼街、里坊
- 城外：四夷馆、四通市、白象寺、景明寺、报德寺、融觉寺…
- 社会：胡商、僧尼、杂技、酒楼、佛诞行像

**可以做到"街—坊—寺"级别的游戏地图**，这是南北朝最强的城市复原资料。

## 五、势力系统设计

**核心势力（550 年前后）**
- 东魏/北齐（高欢—高澄—高洋系，怀朔镇集团）
- 西魏/北周（宇文泰系，武川镇集团）
- 梁（萧氏皇族 + 门阀 + 侯景之乱）
- 后梁（江陵）
- 陈（陈霸先，寒人武将）
- 突厥（新兴势力，6 世纪中期）
- 柔然（衰亡中）、吐谷浑、高句丽（外围）

**势力特性建议**
| 势力 | 特色机制 |
|---|---|
| 东魏北齐 | 军力强、内斗烈、皇帝多昏暴 → "权臣—皇帝"张力机制 |
| 西魏北周 | 府兵制、六官改革、关陇集团 → "制度改革"机制 |
| 梁 | 文化鼎盛、士族繁华、军事虚弱 → "文化资本"与"军事崩塌"反差 |
| 陈 | 寒人崛起、偏安江东 → "草根逆袭"路线 |
| 突厥 | 游牧、狼生神话、锻铁 → 完全不同的玩法（季节迁移、抢掠） |

## 七、"可信度分层"如何呈现给玩家

建议三种模式：
1. **纯游戏模式**：不显示标记，专注玩法。
2. **考据模式**：人物卡上显示 A/B/C 标签，点击可看史料原文与出处。
3. **学术模式**：显示所有史料分歧（如某人的生卒有两种说法）。

参考：《刺客信条》Discovery Tour、《全面战争》的历史说明。

## 八、最小可玩原型（建议先做这个）

**设定**：550 年，晋阳。
**内容**：
- 3 个势力（东魏、西魏、梁）
- 20 个真实人物（高欢已死，高澄、高洋、宇文泰、侯景、萧衍、陈霸先…）
- 10 个事件（河桥、玉璧、侯景叛、台城陷落…）
- 1 张地图（洛阳 + 晋阳 + 邺 + 长安 + 建康，简化）
- 1 个循环：仕官 → 任务 → 升迁 → 参与大事件

**目的**：验证"史料数据 → 玩法"的转化效率，而不是追求完成度。

## 九、复用要点清单（Checklist）

- [ ] 每张人物卡都有 source 与 confidence
- [ ] 事件卡与人物卡互相引用（双向链接）
- [ ] 地名统一使用"古名 + 今地 + 经纬度"
- [ ] 异名（字、小字、胡名、谥号）全部记录
- [ ] 数字（生卒、年份）标注"确定/推算/未知"
- [ ] 保留史料矛盾，不强行统一
- [ ] 宗教事件与政治事件分开建模（但互相影响）
