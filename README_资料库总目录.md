## 一、一句话说明

这是一个"可以直接开始做游戏"的南北朝资料库：
- **古籍全文**：正史、编年、地理、制度、佛道、志怪、类书、文集，双版本（简体通行本 + 繁体校对本），全部可本地全文检索。
- **人物数据**：CBDB 66 万人中的南北朝段 5407 人，含官职、亲属、社会关系、籍贯坐标。
- **研究著作**：汤用彤《汉魏两晋南北朝佛教史》、陈寅恪《隋唐制度渊源略论稿》《金明馆丛稿》《魏晋南北朝史讲演录》等。
- **研究文档**：学习计划、书单、可行性评估、神话素材、游戏落地指南。
- **电子书整理本**：川本芳昭《中华的崩溃与扩大：魏晋南北朝》试读部分（含全部插图，97 页 PDF + 纯文本）。

## 五、CBDB 数据库怎么用

用 DB Browser for SQLite 打开 `cbdb_20260926.sqlite3`，或用 Excel 打开 `CBDB导出\` 下的 CSV。

```sql
-- 查 500-550 年间姓高的人物
SELECT c_name_chn, c_birthyear, c_deathyear, c_index_year
FROM BIOG_MAIN
WHERE c_surname_chn = '高' AND c_index_year BETWEEN 500 AND 550;

-- 查某人的全部官职
SELECT b.c_name_chn, o.c_office_chn, p.c_firstyear, p.c_lastyear
FROM POSTED_TO_OFFICE_DATA p
JOIN BIOG_MAIN b ON p.c_personid = b.c_personid
JOIN OFFICE_CODES o ON p.c_office_id = o.c_office_id
WHERE b.c_name_chn = '高欢';
```
